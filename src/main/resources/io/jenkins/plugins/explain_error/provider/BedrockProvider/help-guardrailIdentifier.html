Optional ID or ARN of an Amazon Bedrock guardrail to apply to every request, for example abc123 or arn:aws:bedrock:us-east-1:123456789012:guardrail/abc123. Requires a Guardrail Version.
The guardrail evaluates the build log sent to the model and the model's answer. When it blocks either one, no explanation is produced and the guardrail's blocked message is reported as the error.
The credentials Jenkins uses for Bedrock need the bedrock:ApplyGuardrail permission on the guardrail. Leave empty to call the model without a guardrail.
