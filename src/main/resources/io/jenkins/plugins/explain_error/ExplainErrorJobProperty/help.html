Overrides the global Automatically explain failed builds setting for this job. Use it to exclude a job that fails often, such as a flaky test job, while automatic explanation is enabled globally, or to explain the failures of this job only while it is disabled globally.

Leave this unchecked to follow the global setting. Builds that already call the explainError() step are not explained a second time. In a Pipeline, the same setting is available as properties([explainErrorJob(autoExplainOnFailure: false)]).
